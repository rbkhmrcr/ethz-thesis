\section{Summary}\label{sec:agg-creds-summary}

This chapter addresses a gap in existing anonymous credential systems. While
later systems decentralise issuance, the issuers as a whole remain responsible
for all attributes. We instead target the setting of distinct issuers without
requiring any coordination between issuers, or indeed between the registration
authority, issuers, and verifiers at any time. The user simply interacts with
each as needed.

We achieve this through constructing an aggregate anonymous credentials system,
in which credentials issued independently by different authorities can be
combined by the user into a single compact credential and presented through one
proof. Issuers do not need to maintain state across users. We take the
certified-key assumption implicit in similar constructions and make it
explicit, introducing the registration authority as its own role, and using
this role to achieve efficient multi-issuer anonymous credentials.
\begin{outline}
  \item the key point: giving the registration authority one job (binding a key to a tag) adds no trust, it learns a key and a tag and is never contacted again, and it is what lets issuers stay uncoordinated and stateless
  \item first instance of the wider argument of the thesis (link to the intro)
  \item ART-Sign makes it concrete: both bind a user to one tag at registration; where the tag is the key, issuers remember what they signed; where the RA signs tag and key together, they do not
\end{outline}

\begin{outline}
  \item optional, broader: many systems contain an unnamed role (whoever certifies a key, assigns an identifier, admits a participant); naming it with a narrow capability can remove coordination
  \item example settings: wallets with credentials from unrelated national registries, or from employers, universities, health services
\end{outline}

We present an instantiation based on structure-preserving signatures, and build
a special-purpose proof for efficiency.
The instantiation combines the $\AGHO$ SPS scheme, our tag-based aggregate
signature scheme $\ATS$ and a Sigma protocol. With $n = 128$ issuers and $k =
64$ disclosed attributes, a presentation takes 20.1\,ms to produce and
31.1\,ms to verify, and these costs scale with $k$, not $n$.
A concrete security analysis of the scheme would be valuable for determining
its real-world security guarantees.
\begin{outline}
  \item concrete security analysis: parameter sizes for a given number of issuers and presentations
  \item open direction: GGM is needed only through AGHO; a rerandomisable SPS under a standard assumption would remove it, at the cost of larger registration signatures
\end{outline}

We briefly outline epoch-based revocation, which would address attributes with
natural expiry dates. However, a more thorough consideration of revocation is
needed before the scheme would be able to support different attribute
revocation policies.
\begin{outline}
  \item revocation of a whole user through their tag, and of single attributes
\end{outline}

The anonymous credential scheme as it stands uses the issuer public keys in the
clear. As the identity of the issuers can reveal information about the user,
recent work has focused on issuer hiding. Adding the property of issuer hiding
to this protocol would be interesting future work.
