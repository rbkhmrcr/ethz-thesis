\section{Construction}\label{sec:tsps-construction}

We construct a threshold SPS scheme generically, from an SPS scheme $\SPS$
whose signing algorithm is decomposable and an MPC protocol with the interfaces
of \Cref{sec:tsps-mpc}. The signing key of $\SPS$ is secret-shared among the
$n$ signers, who never reconstruct it.

\paragraph{Setup.} The signers agree in advance on $(\ell, t, n)$ and the
pairing groups, and abort if any call to $\algo{MPC}$ returns $\bot$.

\paragraph{Key generation and verification.} Key generation runs $\SPSgen$
under the MPC protocol, a direct application of generic MPC that inherits its
security properties. Our proof does not cover this step explicitly, as it
focuses on the separation of signing into offline and online phases.
Verification is $\SPSverify$ unchanged, since it uses no
secret shares, and the distributions of signatures are the same in the threshold
and non-threshold cases.

Evaluating $\SPSsign(\sk, \vec{\msg})$ under MPC, with the message as one more
input, would put every interactive call after the message is known. We instead
split signing into an offline phase, which makes every interactive call before
the message is known, and an online phase, which is local. This depends on the
form of the signing algorithm, which we define first.

\paragraph{Decomposable signing.} A scheme $\SPS$ has decomposable signing if every
signature $\SPSsig \sample \SPSsign(\sk, \vec{\msg})$ on $\vec{\msg} = (\msg_1,
\ldots, \msg_\ell)$ consists of group elements $c_0$, which do not depend on the
message, and $z_1, \ldots, z_k$ of the following form:
%
\begin{equation*}
%
  z_j = c_j \prod_{i=1}^{\ell} \msg_i^{e_{j,i}},
%
\end{equation*}
%
where the group elements $c_0, c_1, \ldots, c_k$ and field elements $e_{j,i}$
depend only on $\sk$ and the signing randomness, and not on the message.

Given sharings of these values, each signer computes its share of the signature
with a linear operation on its own shares, so the online phase is local. Not
every signature scheme has this form. If the message appears inside an inverse,
for example, signing needs an interactive call once the message is known. The
definition does not use the structure-preserving property, so the construction
applies to any signature scheme of this form.

\Cref{prot:tsps-generic} gives the construction $\TSPS$, applied to an SPS
scheme $\SPS$.

\begin{protocolbox}{Threshold structure-preserving signatures}{tsps-generic}

  \begin{description}

    \item[$(\shr{\sk}, \pk) \sample \TSPSgen(\secparam, \ell, t, n)$ :] The
signers do the following:

      \begin{enumerate}

	\item Run $\SPSgen(\secparam, \ell)$ under $\algo{MPC}$: every field
element it samples is a call to $\algo{RandShare}$, and every product of secret
field elements it derives is a call to $\algo{Mul}$.

	\item Compute the shares of the group elements of $\pk$ and $\sk$
locally, by raising the generators to the shares of their discrete logarithms.

	\item Call $\algo{Open}$ on $\pk$ only, which broadcasts each signer's
share $\pk_h$ of it.

      \end{enumerate}

    \item[$\shr{\state} \sample \TSPSoffsign(\shr{\sk})$ :] The signers do the
following:

      \begin{enumerate}

	\item Sample the signing randomness with $\algo{RandShare}$.

	\item Compute sharings of $c_0, \ldots, c_k$ and of every $e_{j,i}$ with
$\algo{Mul}$, $\algo{Inv}$, $\algo{ExpGrp}$ and linear operations.

	\item Store $\shr{\state} = (\shr{c_0}, \ldots, \shr{c_k},
(\shr{e_{j,i}})_{j,i})$. Parts of the state computed locally from $\shr{\sk}$
need not be stored, and each signer computes them from $\sk_h$ when signing.

      \end{enumerate}

    \item[$\SPSsig_h \leftarrow \TSPSonsign(\sk_h, \state_h, \vec{\msg})$ :]
Each signer does the following, as a local operation:

      \begin{enumerate}

	\item Compute the following for each $j \in [1,k]$:
	  %
	  \begin{equation*}
	  %
	    \shr{z_j} = \shr{c_j} \prod_{i=1}^{\ell} \msg_i^{\shr{e_{j,i}}}.
	  %
	  \end{equation*}

	\item Return its shares of $(c_0, z_1, \ldots, z_k)$.

      \end{enumerate}

    \item[$\SPSsig \leftarrow \TSPScombine(\{\SPSsig_h\}_{h \in Q})$ :]
Reconstruct each group element of $\SPSsig$ from the $t+1$ shares, and return
$\SPSsig$.

    \item[$\{0,1\} \leftarrow \TSPSverify(\pk, \vec{\msg}, \SPSsig)$ :] Return
$\SPSverify(\pk, \vec{\msg}, \SPSsig)$.

  \end{description}

\end{protocolbox}

\paragraph{Offline signing.} Each state is used for one message only,
so the signers keep their
states in a queue and delete each one once it is used. The offline phase can be
run repeatedly during quiet periods to build up states for busy ones.
The security proof uses two properties of $\TSPSoffsign$. Every value it opens
is masked by a fresh uniform value, and each component of $c_0$ and each $c_j$ is
computed from its own fresh sharing.

\paragraph{Online signing.} By decomposable signing, each signer only needs
local group operations at this point. No signer communicates with any other during this phase, and its cost is
comparable to that of an ordinary invocation of $\SPSsign$.

\paragraph{Combining.} Combining is performed by whichever party is to hold the signature, and needs no
participation from the signers beyond their having published their shares. The
holder checks the result with $\TSPSverify$, so a malformed share
makes this check fail.

\paragraph{Robustness.} A threshold scheme is robust if signing succeeds
whenever $t+1$ honest signers take part~\cite{EC:GJKR96}. Robustness is a
property of the MPC protocol, and is not given by security with abort.

The threshold scheme is unforgeable whenever the underlying SPS scheme is, given
an MPC protocol that is secure with abort against up to $t$
statically corrupted signers. From the SPS scheme, the construction needs
decomposable signing and existential unforgeability. Strong unforgeability is
not needed, as a TS-UF-1 forgery must be on a message that too few honest
signers signed, and a new signature on a message that was properly signed does
not count. Requiring it would rule out rerandomisable schemes.

\begin{theorem}\label{thm:tsps-construction-security} Let $\SPS$ be an EUF-CMA
secure SPS scheme with decomposable signing, and let the MPC protocol be secure
with abort against up to $t$ statically corrupted signers, over a
linear $(t+1, n)$ threshold sharing. Let every value opened in $\TSPSoffsign$ be
masked by a fresh uniform value, and let each component of $c_0$ and each $c_j$
be computed from its own fresh sharing. For every PPT adversary $\adv$ against the
TS-UF-1 security of $\TSPS$ applied to $\SPS$, there is a PPT adversary $\advB$
such that the following holds for any $n$ and $t$, where $q$ is the number of
queries $\adv$ makes to the offline oracle:
  %
  \begin{equation*}
  %
    \Adv_{\TSPS, \adv}^{\mathsf{TS\text{-}UF\text{-}1}}(\secparam) \leq
\Adv_{\SPS, \advB}^{\mathsf{euf\text{-}cma}}(\secparam) + q \cdot
\Adv^{\mathsf{mpc}}(\secparam).
  %
  \end{equation*}
  %
\end{theorem}

We prove \Cref{thm:tsps-construction-security} in
\Cref{sec:tsps-proof-construction}. Under adaptive corruption, the reduction
loses a factor $\binom{n}{t}$.

\begin{lemma}\label{lem:tsps-adaptive} Under the conditions of
\Cref{thm:tsps-construction-security}, with the MPC protocol secure against up
to $t$ adaptively corrupted signers, for every PPT adversary $\adv$ against the
adp-TS-UF-1 security of $\TSPS$ applied to $\SPS$, there is a PPT adversary
$\advB$ such that the following holds:
  %
  \begin{equation*}
  %
    \Adv_{\TSPS, \adv}^{\mathsf{adp\text{-}TS\text{-}UF\text{-}1}}(\secparam) \leq \binom{n}{t}
\cdot \Adv_{\SPS, \advB}^{\mathsf{euf\text{-}cma}}(\secparam) + q \cdot
\Adv^{\mathsf{mpc}}(\secparam).
  %
  \end{equation*}
  %
\end{lemma}

We prove \Cref{lem:tsps-adaptive} in \Cref{sec:tsps-adaptive}.

In the adaptive case, the loss is a factor of the number of signers with a
dishonest majority, and grows exponentially with the number of signers with an
honest majority.
