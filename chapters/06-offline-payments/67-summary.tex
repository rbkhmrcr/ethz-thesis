\section{Summary}\label{sec:offline-summary}

\begin{outline}
  \item recap: $\OP$, transferable offline payments for a CBDC; payments anonymous
    and unlinkable; a double spender is identified once the conflicting deposits
    reach the central bank
  \item three insights follow
\end{outline}

\begin{outline}
  \item (1) availability does not require removing institutions
  \item the secure element is issued by an institution and trusted for one narrow
    job, refusing to sign a spent token twice; the phone, fully user-controlled,
    does the heavy computation
  \item splitting the JPOK so the secure element's share costs about an ordinary
    signature is what makes it run on existing hardware
  \item same split applies wherever a small trusted component vouches for a
    statement too expensive for it to prove: hardware wallets, identity cards,
    device attestation
  \item the trusted component could be a TEE on the phone instead of a card;
    construction unchanged as long as it enforces single use
\end{outline}

\begin{outline}
  \item (2) accountability defined by an event rather than a person
  \item the auditor recovers an identity only from two conflicting deposits of one
    token, so never touches a rule-following payment
  \item same move as \Cref{chap:txid}, where the capability is limited to a user and
    an epoch
  \item the chapters share a credential layer; next step is a joint analysis, so one
    registration supports online payments traceable under a grant and offline
    payments traced only on double spending
\end{outline}

\begin{outline}
  \item (3) every existing participant can be kept, each constrained in what it
    learns: central bank signs without seeing what it signs, intermediaries see
    only withdrawals and deposits, registration authority never sees a payment
  \item what remains open is mostly practical: fixed denominations keep deposits
    simple; aggregated deposits would reduce the number of tokens users hold, at
    the cost of a more involved deposit proof
  \item (old text also had: performance numbers, divisibility, revocation as the
    sharpest limitation; decide whether to keep)
\end{outline}
