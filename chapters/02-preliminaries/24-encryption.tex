\section{Encryption}\label{sec:prelims-encryption}

Public key encryption schemes enable confidential communication by allowing
anyone possessing a public key to encrypt messages that can only be decrypted
using the corresponding secret key.

\paragraph{Syntax.} A public key encryption scheme consists of the following
algorithms:

\begin{description}

  \item[$(\pk, \sk) \sample \PKEgen(\secparam)$ : ] The key generation
    algorithm outputs key pair $(\pk, \sk)$.

  \item[$\ciph \leftarrow \PKEencrypt(\pk, \msg)$ : ] The encryption algorithm
    encrypts message $\msg$ using public key $\pk$, giving output ciphertext
    $\ciph$.

  \item[$\msg \leftarrow \PKEdecrypt(\sk, \ciph)$ : ] The decryption algorithm
    decrypts ciphertext $\ciph$ using secret key $\sk$, giving output message
    $\msg$.

\end{description}

Public key encryption schemes satisfy correctness and indistinguishability. We
define correctness and one definition of indistinguishability, called
indistinguishability under chosen ciphertext attack, below.

\paragraph{IND-CCA security.} We define indistinguishability under chosen
ciphertext attack (IND-CCA) security using the following security experiment.

\begin{experimentbox}{Indistinguishability under chosen ciphertext
  attack}{ind-cca}

  \begin{enumerate}

    \item The challenger generates $(\pk, \sk) \sample \PKEgen(\secparam)$ and
      sends $\pk$ to $\adv$.

    \item The adversary is given oracle access to $\deco$, which on input
      ciphertext $\ciph$ returns $\PKEdecrypt(\sk,\ciph)$.

    \item The adversary outputs two equal length messages $(\msg_0,\msg_1)$.

    \item The challenger samples $b \sample \{0,1\}$, computes the challenge
      ciphertext $\ciph^\star \sample \PKEencrypt(\pk,\msg_b)$, and sends
      $\ciph^\star$ to the adversary.

    \item The adversary may continue to query $\deco$, except on input
      $\ciph^\star$. They then output a bit $b'$.

  \end{enumerate}

  $\adv$ wins the experiment if $b' = b$.

\end{experimentbox}

The IND-CCA advantage of $\adv$ is defined as follows:
%
\begin{equation*}
%
  \Adv^{\mathsf{ind\text{-}cca}}_{\PKE, \ \adv}(\secparam) = \left| \
  \Pr[b'=b] - \frac{1}{2} \ \right|.
%
\end{equation*}
%
We say the public key encryption scheme $\PKE$ is IND-CCA secure if this
advantage is small for every admissible adversary $\adv$.
